# RikLoot static site (GitHub Pages)

Amazon India affiliate buying-guide site. Plain HTML/CSS/JS — GitHub Pages serves this folder as-is.

## Deploy free on GitHub Pages
1. Push this repo to GitHub.
2. Repo → **Settings → Pages** → Source: **Deploy from a branch** → Branch: `main`, folder: **`/docs`** → Save.
3. The site goes live at `https://<your-username>.github.io/<repo-name>/` in about a minute.

## Add or edit a guide
The HTML pages are generated by the script in `../site-src/`:

- `site-src/guides.py` — the 7 category guides (kitchen, storage, crafts…)
- `site-src/guides_more.py` — topic articles (first kitchen, winter, WFH…)
- `site-src/build.py` — page layouts, home/about/contact/policy text, tracking ID (`TAG`), email

To add an article, copy one entry in `guides_more.py`, change the `slug`, text and picks, then run:

```
python3 site-src/build.py
```

That rewrites every `.html` file in `docs/`. Edit the `.py` files, not the generated `.html`, or your changes will be overwritten on the next build.
Also update `UPDATED` in `build.py` to today's date when you change content.

Each pick is `(name, why, amazon search words)`. The script builds the Amazon link and adds `tag=rikloot-21` automatically.

## Edited directly (not generated)
- `assets/site.js` — contact details (email, phone, WhatsApp, hours) at the top
- `assets/site.css` — styles

## Amazon Associates rules to keep
- Every Amazon link must carry `tag=rikloot-21` (the build script does this).
- Keep the disclosure "As an Amazon Associate I earn from qualifying purchases." on every page.
- Don't show Amazon prices, star ratings or product images unless you use Amazon's product API.
- Write advice, not fake "we tested it" reviews.
